# EnderStrike

EnderStrike is a Minecraft plugin designed for Paper servers, version 1.21.11. It provides players with unique abilities through commands: `/rstrike` for an explosive strike, `/lstrike` for a forward dash, and `/kstrike` for a temporary shield. The plugin includes a scoreboard display above the hotbar with icons representing each ability: an arrow for dash, an explosion for explosive strike, and a shield for the temporary shield. Each ability has a cooldown to prevent overuse: dash has a 15-second cooldown, explosive strike has a 30-second cooldown, and the shield has a 40-second cooldown. The explosive strike does more damage and does not hurt the command user.

## Install

1. Download the plugin JAR file from the releases section.
2. Place the JAR file in the `plugins` folder of your Paper server.
3. Restart or reload your server to load the plugin.

## Use

1. Ensure you are a player in the game.
2. Use the following commands to activate abilities:
   - `/rstrike` - Activates an explosive strike at your location.
   - `/lstrike` - Dashes you forward in the direction you are facing.
   - `/kstrike` - Activates a temporary shield that protects you from damage.
3. Monitor the scoreboard above the hotbar to track cooldowns and active abilities.
